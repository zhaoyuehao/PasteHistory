## PR #4：菜单文案用户化 + 图文合并 + 文本去重

- AGENTS.md 新增硬性规则：每次开工先 fetch 并对齐最新 origin/main 再拉分支（用户明确要求）。
- 菜单文案去技术名词；删除「记录当前剪贴板」（含 ClipboardMonitor.captureCurrent 死代码）。
- **菜单底部空白行根因**：`menuWillOpen` 用 `items.last(where: { $0.title.isEmpty })` 反查统计项，但 separator 的 title 也是空串且排在统计项之后 → 文字写到分隔线上。修复：统计项打 tag 9001，`menu.item(withTag:)` 定位。
- 复合格式：同次复制图+文合并为一条（kind=image 携带 text）；应用拆写（两次 changeCount）用 1.2s 窗口 + 同来源应用 + 类型互补合并进上一条（ClipStore.attachImage/attachText → DB replace 保留 id）。
- 去重：文本指纹 trim 首尾空白后 hash（`ClipItem.textContentHash`）；启动时 HistoryDatabase.migrateTextHashes 幂等重算存量；ClipStore.dedupeExistingTextItems 清理历史重复（置顶优先保留，remove 走 iCloud 墓碑）。冒烟日志确认删了 2 条存量重复。
- 粘贴图文记录时 writeObjects(img) 后再 setString，图文同 item 写回剪贴板。
