## 如何维护

用户可见行为写在首页或对应功能文档；命令与排障步骤集中到开发文档；协议参数集中到同步文档。`AGENTS.md` 保留协作和实现约束，`MEMORY.md` 保留决策背景，避免多处复制同一份操作手册。

修改文档时核对当前 `main` 的代码、脚本和资源。新增路径使用相对链接；示例命令默认从仓库根目录执行，并说明是否会操作真实历史、剪贴板或其他应用。性能数字需要可复现的测量条件；历史截图不作为当前界面的精确验收基线。
