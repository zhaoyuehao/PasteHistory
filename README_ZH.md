# PasteHistory

[体验网页许愿树](https://zhaoyuehao.github.io/PasteHistory/) · [下载 macOS 预览版](https://github.com/zhaoyuehao/PasteHistory/releases)

[English](README.md)

网页体验按 Swift 的许愿树布局与按键分发实现，首屏即显示原生每组八条的完整布局。浏览器保留快捷键和系统集成受网页环境限制，详见[网页实现说明](website/README.md#native-interaction-reference)。 桌面按 1 : 1.618 : 1 居中排列，复制样例与备忘录使用尺寸一致的竖向黄金矩形窗口。

两个窗口精简文案；顶部语言入口仅显示图标与当前语言，移除辅助操作菜单和整页重置功能。

复制样例和备忘录常驻，快捷键提示放在备忘录内；树收起后显示可点击的 ⇧⌘V 唤起提示。整页默认跟随浏览器语言，顶部菜单栏可统一切换英文、简体中文、繁体中文、日文和韩文。

macOS 菜单栏剪贴板历史工具。按 **⇧⌘V** 在桌面许愿树中搜索文本、图片和文件路径，再按回车粘贴到原应用。支持本地 OCR、Mac 间 iCloud 同步和局域网手机访问。

## 构建与运行

需要 **macOS 14+** 和 **Swift 6 工具链**，无需 Xcode 工程或运行时 Blender 环境。

```sh
./scripts/build_app.sh
open PasteHistory.app
```

脚本构建并打包应用，按 Apple Development、本地 PasteHistory 证书、ad-hoc 的顺序选择签名。日常构建使用 **Apple Development**：ad-hoc 重建可能使辅助功能授权失效。

在「系统设置 → 隐私与安全性 → 辅助功能」允许 PasteHistory 后可自动粘贴。未授权时仍会复制选中内容，可手动 ⌘V。应用常驻菜单栏，不显示 Dock 图标。

## 使用

在其他应用复制内容，打开许愿树后直接输入搜索。每组有 8 张历史纸签，另有一张常驻的「手机同步」卡片。树每次在鼠标所在屏幕居中，树枝与空白区域不拦截后方应用的点击。

单击历史纸签打开预览，再单击展开的纸面收回；选字、滚动、双指缩放不会收回。预览内双指缩放作用于整张纸面，键盘焦点留在搜索框。可将历史纸签拖到兼容应用，只复制内容，不移动原文件。

展开、收回和跟随共用阻尼运动状态：连续操作会改变移动中纸面的目标，无需重新播放。卡片从展开到收回保留同一个窗口，阅读内容直接参与动画，结束时不再由快照切换为真实内容。展开途中也可以双指缩放，并保留系统“减少动态效果”支持。

| 操作 | 快捷键 |
| --- | --- |
| 全局打开 / 关闭历史 | ⇧⌘V |
| 选择 / 翻组 | ↑ / ↓；Page Up / Page Down（fn↑ / fn↓） |
| 预览开关 | 空格 / ⌘Y |
| 输入搜索词中的空格 | Shift＋空格 |
| 粘贴 / 仅复制 | 回车 / ⌘C |
| 粘贴第 1–9 条结果 | ⌘1–9，按整个搜索结果编号，不按当前分组 |
| 置顶 / 取消置顶 | ⌘P |
| 删除记录 | 导航状态或搜索为空时按 Delete；否则编辑搜索文字 |
| 先关预览、再关历史 | Esc；输入法组词和原生拖放优先处理取消 |
| 关闭历史 | ⌘W 或点击其他应用 |
| 调整布局 | ⇧⌘M；⌘R 复位，Esc 完成 |

布局调整保留尺寸档位；移动树仅影响当前打开期间。输入法组词时保留自身导航和确认行为。「手机同步」卡片不属于历史，不能删除、置顶或拖出。

## 同步

- **手机**：单击树上的「手机同步」卡片，在可互访的同一局域网扫码。在网页粘贴文本发送到 Mac；也可从 Mac 历史复制文本 / 文件路径或保存图片。刷新二维码会使旧配对失效。HTTP 手机页面不能自动读取剪贴板或离线使用。
- **其他 Mac**：使用同一 Apple 账户并确保 iCloud Drive 可用。同步默认开启，不可用时菜单显示重试入口。记录、图片及删除操作随 `iCloud Drive/PasteHistory/` 文件到达而传播。

手机页面最多获取并搜索 300 条记录。文件记录只包含路径，不传输任意文件本体。详见[同步与安全边界](docs/sync.md)（英文）。

## 数据与隐私

历史位于 `~/Library/Application Support/PasteHistory/`：包括 `history.sqlite` 及 WAL 文件、`images/` 图片目录。设置使用 `com.verdent.pastehistory` UserDefaults 域。备份前退出应用，保留整个数据目录；iCloud 同步不能代替独立备份。

OCR 在本机识别简体中文、繁体中文和英文，搜索也覆盖文本、文件路径、来源应用和图片分类标签。默认忽略密码管理器应用及带保密 / 瞬态标记的剪贴板内容；未标记的敏感文本仍可能被记录，需要时可从菜单暂停。

**本地及 iCloud 文件没有应用层加密。** 手机载荷加密不具备 HTTPS 的保护，应仅在可信局域网使用。通用剪贴板内容到达 Mac 后才被记录，并不持续采集手机历史。
